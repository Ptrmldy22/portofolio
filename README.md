# Portfolio Putri Maulidya

React (Vite) + Tailwind CSS 4.1 + Framer Motion, tema pink soft.

## Menjalankan
```bash
npm install
npm run dev      # buka http://localhost:5173
npm run build    # hasil di folder dist/
```

## Yang perlu kamu edit
- `src/data/content.js`: semua teks, project, skill, link sosial, dan key Web3Forms.
- `public/avatar.png`: foto atau ilustrasi avatar untuk hero.
- `public/cv-putri-maulidya.pdf`: file CV untuk tombol Download CV.
- `src/index.css`: warna tema (blok `@theme`).

## Deploy (Vercel)
1. `git init && git add . && git commit -m "init"`, lalu push ke GitHub.
2. Di vercel.com pilih *Import Project* dan pilih repo ini, lalu *Deploy*.
